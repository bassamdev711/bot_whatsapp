# وصلة — لوحة أحداث واتساب

**وصلة** تطبيق Next.js عربي يوفّر لوحة تحكم لربط حساب واتساب عبر **QR** أو **كود ربط الرقم**، ثم عرض أحداث الرسائل والحالات والوسائط داخل سجل تشغيل واضح.

> لا يستخدم التطبيق خادم API منفصلًا. واجهات الربط تعمل داخل تطبيق Next.js نفسه. لكن استقبال الأحداث في الوقت الفعلي يتطلب أن تظل عملية Next.js شغّالة؛ فلا يصلح للنشر الساكن أو بيئة تتوقف تلقائيًا عند عدم وجود زيارات.

## ما الذي بُني؟

| الجزء | الوظيفة |
|---|---|
| لوحة RTL عربية | حالة الاتصال، تدفق الأحداث، القواعد، ومؤشرات الجلسة. |
| ربط QR | إنشاء رمز فعلي من موصل واتساب عند الضغط على «إنشاء رمز حقيقي». |
| ربط برقم الهاتف | إنشاء كود ربط بعد إدخال الرقم بالصيغة الدولية. |
| سجل أحداث داخلي | يسجل بدء الجلسة، رمز QR، الاتصال، الرسائل الواردة، الحالات، الوسائط، وأخطاء القواعد. |
| قواعد رد قابلة للتحرير | أنشئ ردودًا من الواجهة، واختر العبارة المشغلة والنص والرقم المستهدف، ثم فعّلها صراحةً. |
| قوائم خدمات تفاعلية | أرسل قائمة خيارات رقمية ثم ردًا مخصصًا لكل خدمة يختارها المستخدم. |
| إدارة حالات قابلة للضبط | تأكيد مشاهدة حالة وتفاعل تلقائي اختياري، مع اختيار القلب أو رمز آخر واستثناءات وتخصيص لكل رقم. |
| سجل نشاط محفوظ | يعرض أحداث الجلسة والرسائل والقواعد ويحتفظ بها محليًا بعد تحديث الصفحة أو إعادة التشغيل. |
| إعدادات تشغيلية | تعرض حالة الجلسة والربط والخصوصية، وتتيح إعادة ضبط الجلسة صراحةً. |
| حماية الجلسة والإعدادات | تُحفظ بيانات الاعتماد في `.wasla-session/` والقواعد في `.wasla-data/`، ولا يُرفع أي منهما إلى Git. |

## المتطلبات

يتطلب المشروع Node.js 22 أو أحدث وpnpm. لا تشغله ضمن استضافة ساكنة أو بيئة دوال قصيرة العمر؛ جلسة واتساب تعتمد على اتصال WebSocket مستمر.

```bash
pnpm install
pnpm exec next dev --port 3101
```

ثم افتح `http://localhost:3101` واختر **ربط حساب واتساب**. في التطبيق، افتح واتساب على هاتفك ثم اتجه إلى **الأجهزة المرتبطة** لمسح رمز QR أو إدخال كود الربط.

## بناء وتشغيل الإنتاج

استخدم قيمة صريحة لمتغير البيئة عند البناء:

```bash
NODE_ENV=production pnpm build
NODE_ENV=production pnpm start
```

تحتاج بيئة الإنتاج إلى قرص قابل للكتابة يبقى بين عمليات إعادة التشغيل حتى تحفظ `.wasla-session/` و`.wasla-data/`. إذا حذفت مجلد الجلسة أو اخترت إعادة ضبطها، ستحتاج إلى ربط الحساب من جديد. أما حذف مجلد القواعد فيعيد القاعدة الافتراضية المتوقفة.

## قواعد الأحداث

من القائمة الجانبية اختر **قواعد الأحداث**. ستجد محررًا يسمح بإنشاء أكثر من قاعدة، وتعديل اسمها والعبارة المشغلة ونص الرد وحالتها. حقل **رد خاص لرقم محدد** اختياري: عندما تتركه فارغًا يطبّق الرد على أي مرسل يطابق عبارتك، وعند إدخال رقم بصيغة دولية لا يرد النظام إلا على ذلك الرقم.

القواعد تُحفظ في `.wasla-data/rules.json` عبر واجهة `/api/rules`، ويقرأها موصل واتساب عند وصول كل رسالة. تكون القاعدة الافتراضية متوقفة في البداية، لذلك لا يرسل التطبيق أي رد حتى تقوم بتفعيل قاعدة مكتملة من الواجهة.

هذه الوظيفة مخصصة لردود واضحة ومحدودة في حساب تملكه أو تديره بتفويض، وليست للإرسال الجماعي أو الرسائل غير المرغوبة.

## قوائم الخدمات التفاعلية

من القائمة الجانبية اختر **التدفقات التفاعلية**. أنشئ قائمة باسم واضح، ثم حدد **كلمة البدء** التي يرسلها المستخدم، مثل `خدمات`. اكتب رسالة البداية، وأضف الفروع برقم واسم ورد خاص لكل خدمة. عند وصول كلمة البدء يرسل التطبيق القائمة، ثم يعامل الرسالة التالية من المستخدم كاختيار للخدمة.

| الحقل | مثال | النتيجة |
|---|---|---|
| كلمة البدء | `خدمات` | يرسل المستخدم الكلمة لفتح القائمة. |
| الخدمة `1` | `الاستعلام` | عند إرسال `1` يصل رد الاستعلام المحدد. |
| الخدمة `2` | `الدعم` | عند إرسال `2` يصل رد الدعم المحدد. |
| رقم محدد | `+9665XXXXXXXX` | يقصر هذه القائمة على هذا الرقم فقط. |
| رسالة الخيار غير الصحيح | `أرسل رقمًا من القائمة` | يعيد إرسال الخيارات ويبقي القائمة مفتوحة. |

تحتفظ الجلسة بالخيار المنتظر لمدة **15 دقيقة** في ذاكرة عملية التطبيق؛ إذا انقضت المدة، يحتاج المستخدم إلى إرسال كلمة البدء مرة أخرى. تكون القوائم متوقفة افتراضيًا، ولا تعمل قبل حفظها وتفعيل مفتاحها من الواجهة.

## إدارة الحالات والتفاعل التلقائي

من القائمة الجانبية اختر **إدارة الحالات**. تكون قاعدة الحالات متوقفة افتراضيًا. عند التفعيل، يعالج التطبيق الحالة فور استلامها عبر جلسة واتساب المتصلة، ويمكنه إرسال تأكيد مشاهدة وتفاعل تلقائي. التفاعل الافتراضي هو القلب `❤️`، ويمكن تبديله إلى أي رمز معروض في الواجهة.

| إعداد | السلوك |
|---|---|
| **كل الحالات** | يعالج حالات الجميع باستثناء الأرقام الموجودة في قائمة الاستثناءات. |
| **أرقام محددة فقط** | يعالج الحالات الواردة من قائمة الأرقام المشمولة فقط. |
| **الأرقام المستثناة** | لا يرسل مشاهدة أو تفاعلًا لحالات هذه الأرقام مطلقًا. |
| **تفاعل مخصص** | يعيّن رمزًا مختلفًا لرقم معين ويتقدم على التفاعل الافتراضي. |

تستخدم الأرقام صيغة دولية، مثل `+9665XXXXXXXX`. لا تُفعّل إعدادات الحالات أو ترسل أي تفاعل قبل حفظها وتشغيل مفتاح القاعدة. وبما أن الوصول يصل عبر اتصال واتساب Web قائم، فإن السرعة تعتمد على استمرار جلسة Next.js واتصال واتساب ولا يمكن ضمان زمن تسليم ثابت.

## سجل النشاط والإعدادات

يفتح عنصر **سجل النشاط** قائمة الأحداث الفعلية المحفوظة، بما في ذلك بدء الجلسة وربط الحساب والرسائل والحالات وتنفيذ القواعد أو فشلها. يعرض سطح النظرة العامة آخر ثلاثة أحداث حقيقية فقط؛ لا يضع التطبيق أمثلة ثابتة مكان النشاط. يمكن مسح السجل من نافذته عند الحاجة.

يفتح عنصر **الإعدادات** حالة جلسة واتساب، ورقم الربط عند توافره، وآخر تحديث، وخلاصة الخصوصية. يحتوي كذلك على زر **إعادة ضبط الجلسة**؛ وهو إجراء صريح يسجل خروج الحساب ويمسح بيانات الربط المحلية، ولذلك ستحتاج إلى ربط الحساب عبر QR من جديد.

## واجهات التطبيق

| المسار | الغرض |
|---|---|
| `/` | لوحة التحكم والربط وإدارة الحالة. |
| `/api/health` | فحص جاهزية بسيط للخدمة. |
| `/api/rules` | قراءة قواعد الرد وحفظها من لوحة التحكم. |
| `/api/flows` | قراءة قوائم الخدمات التفاعلية وحفظها. |
| `/api/activity` | قراءة سجل النشاط المحفوظ أو مسحه صراحةً. |
| `/api/status-settings` | قراءة إعدادات مشاهدة الحالات والتفاعل عليها وحفظها. |
| `/api/whatsapp/session` | قراءة حالة الجلسة وبدء QR أو كود الربط. |
| `/api/whatsapp/session/reset` | إنهاء الجلسة ومسح بيانات الربط المحلية صراحةً. |

## ملاحظات الاستخدام

تستند طبقة الربط إلى مكتبة تتعامل مع بروتوكول WhatsApp Web. استخدمها فقط لحساب تملكه أو لديك تفويض واضح لإدارته، والتزم بسياسات واتساب. لا تضع بيانات جلسة واتساب في متغيرات عامة أو مستودع GitHub.
