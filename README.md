# وصلة — لوحة أحداث واتساب

**وصلة** تطبيق Next.js عربي يوفّر لوحة تحكم لربط حساب واتساب عبر **QR** أو **كود ربط الرقم**، ثم عرض أحداث الرسائل والحالات والوسائط داخل سجل تشغيل واضح.

> لا يستخدم التطبيق خادم API منفصلًا. واجهات الربط تعمل داخل تطبيق Next.js نفسه. لكن استقبال الأحداث في الوقت الفعلي يتطلب أن تظل عملية Next.js شغّالة؛ فلا يصلح للنشر الساكن أو بيئة تتوقف تلقائيًا عند عدم وجود زيارات.

## ما الذي بُني؟

| الجزء | الوظيفة |
|---|---|
| لوحة RTL عربية | حالة الاتصال، تدفق الأحداث، القواعد، ومؤشرات الجلسة. |
| ربط QR | إنشاء رمز فعلي من موصل واتساب عند الضغط على «إنشاء رمز حقيقي». |
| ربط برقم الهاتف | إنشاء كود ربط بعد إدخال الرقم بالصيغة الدولية. |
| سجل أحداث داخلي | يسجل بدء الجلسة، رمز QR، الاتصال، الرسائل الواردة، الحالات، الوسائط، وأخطاء القواعد. |
| قواعد رد قابلة للتحرير | أنشئ ردودًا من الواجهة، واختر العبارة المشغلة والنص والرقم المستهدف، ثم فعّلها صراحةً. |
| حماية الجلسة والإعدادات | تُحفظ بيانات الاعتماد في `.wasla-session/` والقواعد في `.wasla-data/`، ولا يُرفع أي منهما إلى Git. |

## المتطلبات

يتطلب المشروع Node.js 22 أو أحدث وpnpm. لا تشغله ضمن استضافة ساكنة أو بيئة دوال قصيرة العمر؛ جلسة واتساب تعتمد على اتصال WebSocket مستمر.

```bash
pnpm install
pnpm exec next dev --port 3101
```

ثم افتح `http://localhost:3101` واختر **ربط حساب واتساب**. في التطبيق، افتح واتساب على هاتفك ثم اتجه إلى **الأجهزة المرتبطة** لمسح رمز QR أو إدخال كود الربط.

## بناء وتشغيل الإنتاج

استخدم قيمة صريحة لمتغير البيئة عند البناء:

```bash
NODE_ENV=production pnpm build
NODE_ENV=production pnpm start
```

تحتاج بيئة الإنتاج إلى قرص قابل للكتابة يبقى بين عمليات إعادة التشغيل حتى تحفظ `.wasla-session/` و`.wasla-data/`. إذا حذفت مجلد الجلسة أو اخترت إعادة ضبطها، ستحتاج إلى ربط الحساب من جديد. أما حذف مجلد القواعد فيعيد القاعدة الافتراضية المتوقفة.

## قواعد الأحداث

من القائمة الجانبية اختر **قواعد الأحداث**. ستجد محررًا يسمح بإنشاء أكثر من قاعدة، وتعديل اسمها والعبارة المشغلة ونص الرد وحالتها. حقل **رد خاص لرقم محدد** اختياري: عندما تتركه فارغًا يطبّق الرد على أي مرسل يطابق عبارتك، وعند إدخال رقم بصيغة دولية لا يرد النظام إلا على ذلك الرقم.

القواعد تُحفظ في `.wasla-data/rules.json` عبر واجهة `/api/rules`، ويقرأها موصل واتساب عند وصول كل رسالة. تكون القاعدة الافتراضية متوقفة في البداية، لذلك لا يرسل التطبيق أي رد حتى تقوم بتفعيل قاعدة مكتملة من الواجهة.

هذه الوظيفة مخصصة لردود واضحة ومحدودة في حساب تملكه أو تديره بتفويض، وليست للإرسال الجماعي أو الرسائل غير المرغوبة.

## واجهات التطبيق

| المسار | الغرض |
|---|---|
| `/` | لوحة التحكم والربط وإدارة الحالة. |
| `/api/health` | فحص جاهزية بسيط للخدمة. |
| `/api/rules` | قراءة قواعد الرد وحفظها من لوحة التحكم. |
| `/api/whatsapp/session` | قراءة حالة الجلسة وبدء QR أو كود الربط. |
| `/api/whatsapp/session/reset` | إنهاء الجلسة ومسح بيانات الربط المحلية صراحةً. |

## ملاحظات الاستخدام

تستند طبقة الربط إلى مكتبة تتعامل مع بروتوكول WhatsApp Web. استخدمها فقط لحساب تملكه أو لديك تفويض واضح لإدارته، والتزم بسياسات واتساب. لا تضع بيانات جلسة واتساب في متغيرات عامة أو مستودع GitHub.
